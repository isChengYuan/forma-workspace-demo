# 序间 Forma · 智能工作平台 Demo

React + Vite 高保真互动演示。包含人事、销售、法务三个业务工作台，以及统一知识、协作和数据分析模块。

## 本地运行

使用 Node.js 22 或更新版本：

```sh
npm install
npm run dev
```

```sh
npm run build
npm test
```

生产文件输出到 `dist/`，资源采用相对路径，可部署到 GitHub Pages 仓库子路径。当前先交付本地预览，等待用户确认后再上传、部署。

## 已实现的演示交互

- 登录校验、退出登录、账号页、工作台切换及单工作台菜单隔离。
- 公共平台九个统一菜单及三个业务中心的全部菜单。
- 首页默认滚动最近7天，可切换时间范围、展示粒度和自定义日期。
- 员工、部门、工作台、功能及模型维度的工时与模拟费用统计，CSV导出。
- 内部知识问答、部门知识范围、无依据提示、引用原文弹窗、问答历史、复制及反馈。
- 文档导入、审核发布、暂停、归档、搜索、预览；发布状态与问答联动。
- TXT/Markdown读取真实文本。PDF/Office文件仅登记元信息，需手动提供原文摘录。
- 待办详情、审批通过/驳回、任务创建及完成；业务记录新建、状态修改及导出。
- 全局搜索、消息已读、默认工作台、管理预算配置与配置变更记录。
- 桌面及移动端布局，键盘搜索和弹窗关闭。

## 演示边界

这是前端Demo，不是生产系统。测试密码写在前端代码中，白名单和角色控制仅用于演示交互，不构成真实安全隔离。所有演示资料均为虚构，请勿存入真实公司文件。

没有后端身份验证、真实模型调用、向量检索、Office/PDF解析、真实签章或业务集成。知识问答使用本地关键词匹配和文档摘录，费用使用虚构模型和模拟价格。文件仅保存文本与元信息，不保存原始Office/PDF文件。

数据保存在当前浏览器的 localStorage，会话保存在 sessionStorage，不在设备间同步。清除本站浏览器数据会恢复初始演示状态。生产版需要独立后端鉴权、文档解析和存储、检索及模型服务。
